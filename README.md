# Offerbiu · 2027 秋招工作台

沿用现有 Hero 风格的前后端项目：真实岗位、投递管理、在线简历编辑、版本记录、日程与 DeepSeek 润色。

**状态：已开发；按要求未执行编译、测试、浏览器验收或真实 AI 调用，不使用 TDD。尚未公网部署。**

## 启动

需要 Node.js 24+。无外部 npm 依赖，不需要安装或编译。

```powershell
node server/index.mjs
```

也可以双击“启动工作台.cmd”，或运行 start.ps1。

- 主页：http://127.0.0.1:4174/
- 工作台：http://127.0.0.1:4174/workspace/
- 岗位库：http://127.0.0.1:4174/workspace/#/jobs

进入工作台后注册自己的账号，没有预设弱密码。以前的 4173 静态预览不能替代后端入口。

## 招聘数据

当前收录 **6,373 条具体岗位，40 家企业／集团、15 个行业**，已按用户要求重新限定来源：

- **企业官网 6,341 条**：包括腾讯、阿里巴巴、字节跳动、滴滴、美团、拼多多、网易、快手、小红书、B站、米哈游、得物、小米、OPPO、华为、vivo、影石，以及中国银行、中核集团等。各企业数量和直达示例见数据来源文档。
- 本次新增 **5,501 条**。按用户要求，滴滴采集完毕后停止查找；携程尚未整理入库，宇树缺少明确2027届依据，均未用通用入口或旧届岗位代替。
- **西北大学就业网 32 条**：包含北森、彩讯、顺丰、九江银行等单位的具体岗位。
- 其他高校来源、企业校招总公告、只列岗位类别的条目均不进入当前岗位库。
- 点击岗位名称或“去官网投递 / 去西大投递”，直达对应岗位详情及投递入口。来源网站可能要求登录，由用户本人提交。
- Base 取具体岗位字段与正文，正文更完整时优先正文；不再混入整场校招覆盖地区。
- `data/job-source-policy.json` 与 `server/job-policy.mjs` 同时限定来源、单岗位路径、岗位编号、届别及投递链接；未来新增企业须先核实其官方专属招聘渠道，再补充规则。
- 原收藏、投递、简历、账号保留。被移除的岗位只作为个人投递历史显示，并标注“已下架”。

维护流程（数据采集与发布，不是测试）：

```powershell
# 可选：刷新百度和腾讯音乐公开职位候选，不直接改动在线岗位库
python scripts/collect-jobs.py
# 读取金证官网和西北大学公开岗位，筛选候选
python scripts/collect-direct-jobs.py
# 扩充经审核的企业官方渠道（保留真实岗位编号、职责、届别和 Base）
python scripts/collect-employer-expansion.py

# 按需读取已支持的知名企业官方岗位
python scripts/collect-famous-jobs.py
python scripts/collect-more-brands.py
# 核对单岗位链接、过滤总公告和实习、执行来源规则，再入库
python scripts/publish-direct-jobs.py
```

只合并新增企业快照、保留现有岗位时运行 `python scripts/publish-direct-jobs.py --merge-only`；该操作不会把旧快照重新核验为实时在招。

需要 Python 和 beautifulsoup4。后两步默认复用同日证据，属于采集快照，不代表实时在招保证；跨日运行会建立新的日期目录。旧 `expand-jobs.py` / `assemble-jobs.py` 已停用，不能再导入其他高校资料。后端代码变更需重启服务，数据发布脚本只更新招聘目录与元数据。

来源、排除原因及单岗位链接见 [数据来源](docs/数据来源.md)。

## DeepSeek

工作台 → 个人设置 → 填写自己的 DeepSeek API 密钥 → 保存。

默认 deepseek-flash，可选 deepseek-v4-pro。也可通过服务器 .env 设置 DEEPSEEK_API_KEY / DEEPSEEK_MODEL，个人配置优先；参照 .env.example。

只有用户确认润色后才调用。默认发送所选段落及目标岗位要求，不自动携带联系字段。建议需手动采纳，原文变化时阻止覆盖。没有密钥会明确提示，不返回模拟结果。

## 边界

- 数据库：storage/offerbiu.sqlite；个人 API 密钥通过 AES-256-GCM 加密；本机加密文件在 storage/.encryption-key。整个目录均应作为敏感资料保存。
- 默认仅监听本机。正式上线需 HTTPS、APP_ORIGIN、COOKIE_SECURE=true、持久化磁盘、备份、邮件验证/找回等配置。
- PDF 通过浏览器打印另存；不含 Word 导出、已有 PDF/Word 自动解析或文件上传。
- 日程是站内记录，不发短信、邮件或系统推送。
- 未测试，不宣称生产可用。DeepSeek 需要有效密钥和额度，尚未实调。

## ResumeCollection 模板与图片（2026-09-19）

新增仓库 004、005、018、022、023 五套可编辑适配版，模板总数为11。模板画廊优先展示新增款，并提供源目录、仓库许可与原版图片链接。

编辑器 → “头像 / 作品图”：可添加一张头像与最多三张作品图，支持更换/移除、头像形状与显示位置、图片说明与顺序。原图支持 JPG/PNG/WebP、每张8 MB以内；浏览器自动压缩为JPEG，头像最多180 KB、配图每张最多300 KB。图片随简历及历史版本保存，PDF/独立HTML/JSON导出包含图片；旧的纯文字JSON仍可导入。服务端保留文字大小限制，仅将有会话的简历写入请求上限调为2 MB。

图片不公开存入assets，也不发送给DeepSeek；随账号简历保存在受登录和归属校验保护的数据库内。访客草稿仍为浏览器会话保存。按原要求未编译或运行应用测试。
