# Offerbiu

**面向 2027 届校招的本地优先求职工作台。** Offerbiu 将官方岗位浏览、求职进度、简历编辑和 AI 求职材料准备放在同一个本机 Web 应用中，让求职者能从发现岗位，一直跟进到记录实际投递。

AI 帮助整理本人确认过的事实、分析岗位要求和起草申请材料；重要判断和实际投递都由本人检查、确认。Offerbiu 不会替你向企业提交申请。

## 能做什么

- **查找校招岗位**：按企业、行业、方向、城市、Base 和来源筛选，查看岗位要求，并跳转到企业官网或西北大学就业网的具体岗位页面。职位目录是带来源的采集快照；招聘状态会变化，过期岗位可能下架。
- **管理求职进度**：记录收藏、投递状态、简历版本、后续事项和备注，并查看每次进展。
- **确认个人经历**：从已有简历导入待核对的事实，逐项确认信息和偏好，再用于岗位评估与材料准备。
- **评估岗位**：主动选择岗位后，对照已确认的个人信息和岗位要求，查看通过、不符合或需要核实的条件，以及引用依据。资料不完整时不提供可比较分数；分数不代表录用概率。
- **准备申请材料**：为岗位起草简历段落和网申字段；检查字数和事实依据，独立复核建议，再由你选择采纳内容。
- **记录实际投递**：提交申请后，确认岗位、所用简历版本和实际填写内容，保存为可独立查看的投递记录。
- **编辑简历**：在工作台中直接编辑预览，切换 15 套模板、调整模块顺序和版面，并管理头像与作品图。可导出 JSON、独立 HTML，或通过浏览器打印为 PDF。
- **安排后续事项**：记录笔试、面试、截止日期和跟进任务。

AI 会将当前操作所需的文字发送到所选模型服务，模型建议需人工核对；岗位评估会在发送已确认经历和岗位要求前征求同意。头像和作品图不会作为 AI 输入。

## 本机运行

需要 **Node.js 24 或更新版本**。无需安装 npm 依赖或执行前端构建。

在 Windows 上可双击项目根目录的 `启动工作台.cmd`，或在 PowerShell 中运行：

```powershell
node server/index.mjs
```

默认只监听本机 `127.0.0.1:4174`。启动后打开：

- 首页：<http://127.0.0.1:4174/>
- 求职工作台：<http://127.0.0.1:4174/workspace/>
- 岗位库：<http://127.0.0.1:4174/workspace/#/jobs>
- 简历模板：<http://127.0.0.1:4174/workspace/#/templates>

首次使用时，在工作台创建账号。浏览岗位无需登录；投递、个人经历、评估记录和简历版本保存在各自账号中。访客可先编辑简历草稿。

## 配置 AI

可使用个人设置中的模型配置。也可以在本机创建 `.env`，设置服务端默认 DeepSeek：

```powershell
Copy-Item .env.example .env
```

在 `.env` 中填写自己的密钥：

```env
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-flash
```

填写服务端默认密钥后重启应用。个人密钥优先用于该账号；也可为账号配置 OpenAI 兼容的自定义服务。当前代码默认模型见 `.env.example` 和个人设置页面。

**不要将真实密钥写入 README、提交到 Git 或粘贴到公开 issue。** `.env` 和本机数据目录已加入忽略规则；`.env.example` 仅展示配置格式。

## 数据与部署边界

- 登录账号数据默认保存在本机 `storage/` 的 SQLite 数据库中，不会自动同步到云端。备份数据库时，请同时妥善保存加密资料目录。
- AI 请求仅在用户主动执行并确认后发送给所选模型服务。访问该服务需遵守其数据处理政策；用户个人配置的服务商会自行处理收到的数据。
- 工作台保存投递信息并提供官方申请链接，不会自动填写或提交企业网申。
- PDF 由浏览器打印生成；项目不提供 Word 导出或 Word/PDF 简历自动解析。
- 默认启动地址仅供本机访问。公网部署需自行配置 HTTPS、`APP_ORIGIN`、安全 Cookie 和持久化存储；仓库不代表已经完成公网生产部署。

招聘数据的纳入规则和采集维护方法见[数据来源说明](docs/数据来源.md)。岗位状态与企业招聘页面可能不同步，请以岗位来源页面为准。

## 开发与验证

运行自动化测试：

```powershell
node --test tests/*.test.mjs
```

测试使用隔离的临时数据库和模拟模型响应；测试通过不代表每家企业的岗位仍在招聘，也不代表真实模型的建议无需审核。近期开发及浏览器验收记录见[AI 求职工作流验收记录](docs/AI求职工作流融合验收记录.md)和[简历模板验收说明](docs/新增开源简历模板.md)。

## 目录结构

```text
index.html, styles.css, app.js     品牌主页
workspace/                         求职工作台、岗位、简历编辑器
shared/                            简历模板、图片处理与共享数据规则
server/                             HTTP API、SQLite、账号与 AI 工作流
server/migrations/                  增量数据库迁移
data/jobs-2027.json                 已采集的岗位目录
data/sources/                       岗位来源快照与审核材料
assets/resume-templates/            模板来源、许可证与授权说明
scripts/                            岗位证据检查及数据采集工具
tests/                              隔离数据库和模拟模型的自动化测试
storage/                            本机运行数据，不提交到 Git
```
