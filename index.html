03 / GOOD TO KNOW

开始之前，你可能想知道。

还没开始投递，也可以使用吗？+

可以。从收集感兴趣的岗位、整理简历版本开始，再逐步补充截止日期和投递计划。工作台可以跟着你的求职进度慢慢完善。

这里能直接向公司投递简历吗？+

这里帮助你整理岗位和跟进进度。实际投递仍需前往企业招聘官网或指定渠道完成，再回到工作台记录进展。

工作台里有哪些功能？+

你可以浏览 2027 届官方校招岗位，建立自己的投递清单和日程，使用三套模板在线编辑简历、保存历史版本并打印为 PDF。配置自己的 DeepSeek API 密钥后，可对选定段落生成润色建议，由你确认采纳。首页展示区使用示例内容，真实岗位请进入工作台查看。
