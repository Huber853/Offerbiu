## 来源与岗位准入

- 仅接入企业官网、企业明确使用的专属招聘系统，以及西北大学就业网 `jczx.nwu.edu.cn`。其他高校不作为本批来源。
- 每条保留真实岗位编号、职责、要求、Base、2027届依据、详情/投递链接和采集时间。首页、职位列表、招聘总公告不能充当岗位。
- 飞书、北森、Moka等均使用已核实的企业专属门户；允许域名、单岗位路径、查询参数或片段中的岗位ID由 `data/job-source-policy.json` 和前后端发布规则共同约束。
- 腾讯为腾讯招聘官网104条，腾讯音乐为独立招聘主体37条。此前腾讯脚本读取限制已解决，用户提供的AI全栈工程师链接已入库。
- 华为70个职位按官网广告ID计数，同职位的多个岗位意向合并展示职责和要求，不拆成多条。投递时在华为官网选择意向、部门及地点。
- 中国银行保留247条岗位，授权依据为其官网2026-09-03招聘公告和2027校园招聘专题，单岗位申请页登录后保留岗位ID。中核成员单位及银行分支单位单独展示。

## 分类、Base与缺失字段

- 职位方向和行业为本站整理；原始分类保留在 `category_raw`，原始地区保留在 `cities_raw`。
- 补充AI、数据分析、软件基础设施、硬件、运营、职能等方向；企业、企业性质、行业、方向和Base可组合筛选。
- 多城市仍保留在同一条岗位中；将“深圳市/东莞市”拆成深圳、东莞两个可筛选地点，避免遗漏。港澳及海外地点按原文保留层级，不推算未公布的城市。
- 同企业、标题、Base、职责、要求和用人单位完全相同的重复广告只保留一条。原广告ID去重在前，内容去重在后。
- 不编造薪资、截止日期、学历或招聘人数。相对日期不强制转成绝对日期；缺失日期不影响页面显示。

- 新来源证据在 `data/sources/2026-09-18-brands/` 与 `data/sources/2026-09-19-brands/`；发布统计见后者 `delivery-summary.json`。每条岗位保存 `source_file`；华为还保存岗位意向来源文件。
- 旧官方来源证据在 `2026-09-17-employers/` 和 `*-official/` 目录，原始采集时间保留。整理日期不代表所有旧岗位已重新访问。
- `scripts/collect-famous-jobs.py` 与 `scripts/collect-more-brands.py` 读取公开岗位；`scripts/publish-direct-jobs.py --merge-only` 按白名单合并种子与数据库，保留个人数据。
- 本次没有编译、应用测试、TDD或本地浏览器验收。仅进行了官网公开数据读取、文件写入和数据库统计。来源状态以用户打开投递页时为准，可能要求本人登录。
