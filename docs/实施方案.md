# Offerbiu 完整项目实施方案

日期：2026-09-16。

## 评估

现有项目是无依赖的 HTML/CSS/JavaScript 主页，已有 Hero、滚动步骤展示与人物动画；交互工作台只是演示，尚无账号、数据库、真实岗位或 AI 服务。

本次保留主页视觉，扩展为 Node.js 24 + SQLite + 原生浏览器模块的完整本地可运行项目。使用 Node 内置 HTTP、crypto、SQLite 和 fetch，避免引入必须编译的前端链。数据库通过参数化语句持久保存，前后端同源通信。

## 实施范围

1. 主页保留设计，主按钮进入真实工作台。
2. 邮箱密码注册、登录、退出；密码加盐哈希；服务端会话与 HttpOnly Cookie；每个用户独立访问自己的数据。
3. 2027 校招岗位库：约 200 条真实官方招聘岗位，搜索、城市/企业/方向筛选、来源详情、收藏到投递清单。保留外部岗位 ID、招聘项目、届别依据、采集时间与原始来源。
4. 投递管理：状态、简历绑定、备注、时间节点、岗位链接；修改写入数据库。
5. 待办和日程：笔试、面试、截止、跟进；首页统计来自真实用户记录。
6. 简历中心：三套模板（经典蓝、极简黑白、技术清晰版）；基础信息、教育、实习、项目、技能、荣誉可直接编辑；实时排版预览、保存版本、恢复历史、JSON 导入导出、打印为 PDF。
7. DeepSeek 润色：用户在软件内设置密钥；后端调用官方接口；选择模块和目标岗位，展示修改前后与建议，经用户采纳后写回；生成记录保留原始简历快照。模型默认采用官方当前文档列出的 deepseek-flash，可切换 deepseek-v4-pro。
8. 配置、启动脚本、操作说明、岗位来源台账。

## 数据原则

- 以独立岗位记录计数，同一个官方岗位 ID 不因多个城市重复计数。
- 仅收录有明确 2027 届依据的全职校园招聘；不拿不限届日常实习或 2026 届岗位凑数。
- 优先官方接口/官网；空缺字段保留空值，不推算薪资、截止日期或学历。
- 原始 JD 若仅能访问摘要，界面明确标注摘要，保留官方详情链接。
- 采集是当前快照，不承诺持续实时更新；官网状态可能在采集后变化。

## AI 边界

用户指定 DeepSeek。仅在用户点击润色并同意发送所选内容后调用；默认不发送姓名、电话、邮箱等联系信息。服务端加密保存用户密钥，密钥不返回前端，也不写日志。AI 不得虚构学历、经历、数字或技能；结果需要用户采纳。

## 执行与交付

按用户明确要求，不使用 TDD，不运行编译、测试、自动化验收或浏览器验收。只进行开发、真实招聘信息采集、必要文件操作和启动交付。因此交付应标注“已开发、未测试”，不能宣称通过测试、AI 实测或生产验收。

本次交付本地可运行的全栈项目；正式公网服务另需服务器、HTTPS、数据库备份和邮件找回等上线配置。
