# 校招手册的界面与动效

首页预览包含「查岗位」「准备简历」「跟进进度」三个页签。浏览相应章节时，预览随自然滚动切换。也可以点击页签，或用方向键、Home 和 End 切换。页面顶部默认显示岗位库。启用系统「减少动态效果」后，预览直接切换。

「手册目录」右侧复用原有的人物动画，目录进入视野后播放两轮。「准备简历」页签显示笔记本电脑人物，其余页签显示挥手人物。系统减少动态效果时展示静态帧。

首页岗位索引显示已有的官方链接检查时间，标题旁常驻内联 SVG 企鹅。岗位结果、投递状态和简历保存提示使用文本、边线和选中态。

首页交互由 `app.js` 和 `motion.css` 实现。工作台和首页共用 `shared/tokens.css`。简历打印继续使用独立的 `workspace/resume.css`。
