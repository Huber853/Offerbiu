# 工作台 UI 与轻量动效

本轮沿用蓝白 Hero 风格，更新工作台应用外观。没有替换招聘数据或简历内容，简历导出继续使用独立的 resume.css。

## 视觉与贴图

- 更清晰的标题卡片、导航选中态、白色面板和柔和蓝紫背景。
- 岗位卡片增加聚焦描边与轻量悬停，模板卡片增加纸张浮起效果。
- 总览/岗位/投递使用挥手人物，模板/简历/日程使用笔记本人物，编辑器横幅使用小尺寸写作人物。
- 复用原项目 assets/career-characters.png（内置ImageGen生成），以4×2背景位置切帧，未新增第三方图库或网络字体。
- 人物、文件便签与星星均是装饰元素，不承担按钮功能，不遮挡操作；窄屏缩小或隐藏部分场景。

## 动效

- 卡片进入视野后短距离渐显，首次显示的实际统计数字平滑递增。
- 保存、收藏、采纳等真实成功反馈出现后，短暂播放轻量纸屑动画；不对失败提示庆祝。
- 右上角“动效开启/暂停”切换，偏好保存在当前浏览器。
- 遵循系统 prefers-reduced-motion；系统减少动态时不允许开关覆盖系统偏好。
- 人物在视野外及标签页后台暂停；使用IntersectionObserver和requestAnimationFrame，不轮询业务接口。

## 实现范围

workspace/delight.css 与 workspace/delight.js；main.js 初始化，ui.js 发出本地成功反馈事件，workspace/index.html 加载样式。

按用户既有要求，没有编译、应用测试或本地浏览器交互验收。交付为代码、素材复用及启动后的本地入口，不代表已验证所有屏幕尺寸与浏览器动画表现。
