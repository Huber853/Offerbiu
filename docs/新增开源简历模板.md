## 使用与适配

- 沿用同一个编辑器和结构化字段，支持纸面编辑、撤销、主题色、字号、行距、模块隐藏、头像与作品配图，以及 PDF / HTML / JSON 导出。
- Bill Ryan 的 LaTeX 版式转换为本地 HTML/CSS，无需安装 TeX。Stack Overflow 不运行 Svelte，Kendall 不引入 Bootstrap，Macchiato 不引入远程图标。
- 使用本机中文字体，编辑和导出的模板不请求 Google Fonts、外部 CDN 或模板服务。HTML 内联样式可离线查看；不附带上游字体文件。
- Kendall 的技能、荣誉固定在右栏；Macchiato 的联系方式、技能固定在左栏。其余模块在主栏内排序，各栏内可调整顺序；编辑器已提示固定栏位。隐藏保留数据，切换模板保留正文与用户顺序。点击“恢复默认排版”可采用当前模板的初始顺序。
- PDF 使用浏览器打印的 A4 分页。双栏打印保留分栏，并处理章节标题与首条经历之间的分页衔接。连续编辑画布仍以打印预览作为最终页数。
