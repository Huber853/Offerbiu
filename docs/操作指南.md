# Offerbiu 工作台操作指南

## 1. 启动

电脑需要 Node.js 24 或更新版本。双击根目录“启动工作台.cmd”，保持窗口运行。

- 主页：http://127.0.0.1:4174/
- 工作台：http://127.0.0.1:4174/workspace/
- 岗位库：http://127.0.0.1:4174/workspace/#/jobs

不需要 npm install，也没有编译步骤。以前的 4173 端口是纯静态预览，不能提供本次后端功能。

## 2. 创建账号

进入工作台后选择“创建我的工作台”，填写称呼、邮箱、8 位以上密码。邮箱目前作为登录标识，不会发送验证邮件，也没有邮件找回。账号、简历、待办与投递保存在这台电脑的 SQLite 数据库；不是浏览器临时缓存。

未登录也能浏览岗位和模板。每个账号只会读写自己的简历、投递与 AI 设置。

## 3. 岗位与投递

1. 打开“校招岗位库”，选择全部岗位、企业官网或西北大学。
2. 按行业、招聘单位、Base、岗位方向和批次筛选；搜索支持公司名、岗位名及技能。
3. 点击岗位名称或“去官网投递 / 去西大投递”，在新标签打开对应岗位的详情和投递入口。页面可能要求登录企业账号或校内账号。
4. “查看详情”在工作台内展示正文、条件、Base、岗位编号、来源与采集时间。
5. “收藏岗位”仅保存在个人清单，不会向企业提交申请。真实投递需本人在来源页面完成。
6. 在“我的投递”记录状态、投递日期、下次跟进、备注，并绑定简历版本快照。

当前 6,373 条均为具体岗位：企业官网 6,341 条、西北大学 32 条。知名企业快捷按钮显示岗位数量，点击后可继续叠加 Base、方向、行业及企业性质筛选。新增企业性质筛选，可结合企业／集团、行业、岗位方向与 Base 查找；中核成员单位及中行分支机构在卡片中单独展示。中国银行的单岗位申请链接会先要求登录，并保留选定岗位。其他高校资料和总招聘计划已下架；不能确认具体投递页的条目不显示。工作地点来自岗位自身，未明确的保留为空。

“已下架（历史记录）”表示旧收藏不再符合当前目录来源规则或链接待核实；原投递进展与简历快照不会被删除。这些条目不参与当前岗位搜索和 AI 目标岗位选择。

## 4. 在线编辑简历

1. 从“模板与工作室”选择十一套模板之一，直接进入沙箱编辑；未登录也能先写草稿。
2. 给简历按方向命名，例如“数据分析方向”。
3. 左侧切换基本信息、教育、实习/工作、项目、技能、荣誉模块。
4. 文本输入即更新右侧预览；点击“保存简历”后写入数据库。
5. 教育、实习和项目支持新增、删除条目。
6. 模板可随时切换，不改变内容。可调整字号、颜色、行距、模块显示与顺序；空白或隐藏模块不会导出。
7. 点击“存入我的简历”登录并保存；草稿只保存在当前浏览器会话，关闭会话前建议存入账号或导出 JSON。
8. 点击右侧纸面文字可直接编辑，详情见《简历工作室》。
7. “版本记录”可以恢复旧版；恢复会创建新版本，保留历史。
8. 可导出 JSON 备份，也可在简历中心重新导入。
9. 点击“打印 / PDF”，在浏览器打印窗口选择“另存为 PDF”。建议 A4、缩放 100%、关闭浏览器页眉页脚；长内容由浏览器分页，实际分页取决于字体和打印设置。

PDF/Word 文件自动解析和 Word 导出不是本次功能；当前简历数据采用结构化表单与 JSON 导入导出。

## 5. 连接 DeepSeek 与润色

1. 在“个人设置”填写你自己的 DeepSeek API 密钥。不要把密钥发到聊天里。
2. 选择 `deepseek-flash` 或 `deepseek-v4-pro` 并保存。保存不会产生 AI 请求，也不验证余额或密钥有效性。
3. 在简历编辑器写下一段真实经历，点击“AI 润色”。
4. 选择段落、目标岗位（来自我的投递）和润色方向。
5. 核对“即将发送的原文”，勾选数据发送说明后开始。只发送所选段落与岗位要求，不自动加入姓名、邮箱、手机等联系字段。
6. 系统通过服务器调用 DeepSeek 官方 API。调用可能消耗 DeepSeek 账户额度。
7. 对比原文、改写和待补充事实。确认后“采纳到简历”，生成新版本。
8. 生成记录保留原始版本、原文和建议，可在“AI 润色记录”回看。

如果你修改了原段落后再采纳旧建议，系统会阻止覆盖并提示手动合并。AI 可能出错，须本人核对经历、数字与职责。

密钥通过 AES-256-GCM 加密保存在数据库；本机加密文件与数据库分开，但均在同一台电脑上。能读取整个 storage 目录的人仍可能解密，因此应妥善保管本机和备份。

## 6. 日程

“日程与待办”可添加面试、笔试、截止、跟进事项。点击日期筛选当天安排，点击复选框完成任务。这里是站内日程显示，不包含浏览器推送、短信或邮件提醒。

## 7. 数据备份

- 设置页的“导出我的数据”导出投递、待办、简历，不含密码和 API 密钥。
- 完整迁移：先关闭服务，再备份整个 `storage` 目录（包括数据库和 `.encryption-key`）。不要只复制正在写入的 SQLite 主文件。
- 请勿将 `storage` 或 `.env` 提交到 Git 仓库；已添加忽略规则。
- 执行岗位采集脚本后重启服务，更新的数据将导入数据库。

## 8. 当前交付边界

按要求未执行编译、测试、浏览器验收或真实 DeepSeek 调用。项目已开发，功能质量尚未经过测试验证。

默认服务只监听本机。正式上线需配置 HTTPS、持久化目录、访问域名、安全 Cookie、备份与邮件找回机制；本次未公网部署。

## 图片上传

进入简历工作室 → “头像 / 作品图”，上传头像或最多三张作品图。支持JPG、PNG、WebP，单张8 MB以内，系统自动压缩。更换或移除可撤销；选择显示形状与位置后，点击保存。图片随PDF、HTML、JSON导出及历史版本保存。
