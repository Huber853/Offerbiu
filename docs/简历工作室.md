# 简历工作室

## 入口与使用

打开本地工作台的“模板与工作室”，选一套模板。也可直接访问 http://127.0.0.1:4174/workspace/#/studio/classic 。

1. 点击“快速生成”，填写姓名、求职方向、联系方式、学校、专业、简介和技能。系统按真实输入生成初稿，不编造经历。
2. 左侧补充教育、实习、项目、技能和奖项，也可点击右侧纸面现有文字直接编辑；纸面编辑会同步左侧内容。
3. 展开“排版与模块”，调整主题色、字号、行距、段间距，隐藏模块或上下移动排序。隐藏不会删除内容。
4. 使用顶部撤销/重做；从模板下拉框切换版式，保留内容。十九套版式均支持相同字段。
5. 本地草稿自动保存在当前浏览器的本机存储（按登录账号和入口模板区分），刷新或重新打开可继续；清除站点数据或换设备前，需导出 JSON 或点击“存入我的简历”。
6. 登录后保存到个人数据库，可继续修改、查看版本或使用已有 DeepSeek 段落润色流程。AI需先配置个人或服务端密钥；不会自动调用或自动采纳。润色先按资深 HR 修订规则检查真实性，只给出建议；点「采纳到简历」之后才会写入新版本。
7. PDF通过浏览器打印的“另存为 PDF”导出。右侧是连续A4宽度编辑画布，最终分页以打印预览为准。HTML含内联样式、无外部字体依赖；JSON可再次导入继续编辑。

## 沙箱与保存方式

- 预览运行于带 sandbox="allow-same-origin" 的 iframe，没有 allow-scripts。预览文档的 CSP 禁止脚本、网络连接、表单提交与外部资源，仅允许内嵌 data 图片和内联本地样式。
- 编辑事件由父页面绑定，结构化字段始终按文本转义，不执行用户HTML/CSS/JS。粘贴仅保留纯文本。
- 服务端继续校验模板ID、个人账号归属、字段长度及版本号；design字段只接受允许的颜色、字号、行距、顺序与隐藏项。
- 不接受任意脚本模板上传，也不提供服务器代码执行。这是简历排版编辑沙箱。
- 账号简历的未保存修改会缓存到本机浏览器，重新打开时可选择恢复；账号已有新版本时会提醒核对。草稿保存在当前浏览器，清除站点数据或换设备前请保存到账号或导出 JSON。

## 上传头像与作品图

- 进入任意简历的“头像 / 作品图”模块，选择JPG、PNG、WebP。单张原图不超过8 MB；也可点击纸面头像区域进入该模块。
- 头像可更换、移除、隐藏；可选择跟随模板、圆形、圆角或方形，调整完整显示/填满相框及上下左右取景位置。
- 作品或证书配图最多3张，可添加说明、上下移动、删除。作品模块可在“排版与模块”中排序或隐藏，头像通过独立开关控制。ResumeCollection 双栏的联系方式与技能固定在侧栏；Kendall 和 Chikorita 的技能、荣誉固定右栏，联系方式在抬头；Macchiato 的联系方式、技能固定左栏。其他模块在主栏内按顺序排列，栏内模块可排序。
- 浏览器重新编码为压缩JPEG，透明背景转白色，原始EXIF不作为简历字段保存。头像最多180 KB，配图每张最多300 KB。
- 图片保存于简历JSON内，跟随账号归属、版本记录及投递快照；不创建公开图片URL。需要点击“保存简历”或“存入我的简历”才持久写入数据库。
- 导出的JSON可还原图片与显示设置，HTML为内嵌图片，PDF打印包含当前可见图片。AI润色只发送选中的文字、已确认事实和岗位要求，不发送头像或作品图。
- 后端限制图片数量、数据URL类型、文件头和大小；仅接受JPEG/PNG/WebP，不接受SVG、远程图片地址或脚本。

以上图片功能为早期批次的实现记录；本次新增模板的头像、配图与分页检查见 [新增开源简历模板](新增开源简历模板.md)。

## AI 润色如何检查

点击「润色此段」并同意发送后，模型先遵守一份资深 HR 修订技能，再返回建议。技能只允许使用选中段落、已确认的经历事实和本次岗位说明。动词强度不得超过原文：支持/协助 < 参与 < 负责 < 推动 < 主导。缺数字时保留原句并标出缺口，不编造指标，也不把岗位要求写成本人经历。没有目标岗位时，只整理清晰度和可信度，不假设一个目标职位。

建议旁边会显示 HR 初看：第一眼判断、具体问题和改完仍要核对的点。原文在你点「采纳到简历」之前保持不变。

技能改编自 MIT 许可的 [coinluu/resume-jd-optimizer-cn](https://github.com/coinluu/resume-jd-optimizer-cn)，许可证和改编范围见 [server/prompts/NOTICE.md](../server/prompts/NOTICE.md)。
